## 사용법

1. 우분투 OS 부팅 디스크(`USB A`)를 준비하고, `hardware_check.sh` 스크립트를 다른 USB(`USB B`)에 복사해주세요.
2. 배송받은 컴퓨터에 `USB A`를 꽂고 전원을 켭니다.
3. 우분투 부팅 후 인터넷(랜선 또는 와이파이)을 연결해주세요. (`smartmontools` 패키지 설치에 필요합니다.)
4. **[!중요!] OS를 SSD에 직접 설치하지 말고, 반드시 `Try Ubuntu`를 선택해 USB 부팅 상태를 유지하세요.**  
   *(부품 바꿔치기나 초기 불량이 발견되었을 때, 판매처에서 "OS를 설치했으니 반품/환불이 불가하다"고 주장하는 상황을 사전에 차단하기 위함입니다.)*
5. `USB B`를 컴퓨터에 연결합니다.
6. `USB B` 폴더를 열어 스크립트를 바탕화면(Desktop)으로 복사한 뒤, 바탕화면에서 우클릭 → `Open in Terminal`을 누릅니다.
7. 아래 명령어를 입력해 스크립트를 실행하세요.
   ```bash
   sudo bash hardware_check.sh
8. 실행이 완료되면 텍스트 파일이 하나 생성됩니다. 
사용량이 4시간이 넘은 부품은 경고 문구가 표시됩니다. (중고부품 확인목적) 


9. 참고1) 줄바꿈 오류 발생 시: Windows에서 파일을 수정해 CRLF 줄바꿈으로 바뀌어 실행 오류가 난다면, 터미널에 아래 명령어를 먼저 입력한 뒤 다시 실행하세요.
    ```bash
    sed -i 's/\r$//' hardware_check.sh
10. 참고2) 파워쉘 몰라서 윈도우버전은 없습니다. 

11. 참고3) txt_result_example에 실행결과의 예시를 올려뒀습니다.
